# Online Course and Learning Platform Analysis

## Project Overview
This project analyses online course data using Python to understand course categories, ratings, enrolment patterns, and pricing.

## Objectives
- Explore online course data.
- Analyse course categories and popularity.
- Study student enrolment patterns.
- Visualise data using charts.
- Identify useful insights from the dataset.

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Project Files
- `Online_Course_Learning_Analysis.ipynb` — Python code, analysis, and outputs.
- `online_courses_uses.csv` — Dataset used for analysis.

## How to Run
1. Open the notebook in Google Colab.
2. Upload the CSV dataset if required.
3. Run the notebook cells in order.

## Conclusion
This project demonstrates the use of Python for data exploration, analysis, and visualisation of online course information.
